# 牙醫診所排班系統

給牙醫診所用的醫師與助理排班系統。醫師班表、助理人數、排休申請、一鍵排班、助理確認、正式公告，都在同一個網頁裡完成，手機也能用。

裡面的醫師、助理都是**範例名字**，要換成你自己診所的人和規則。

## 這個版本

- **本機模式**：資料存在你自己的瀏覽器，不用登入，打開就能用。
- 換一台電腦或換一個瀏覽器，資料不會跟著過去（可以用「資料工具」匯出、匯入備份）。
- 要讓全診所的人一起用（多台裝置共用同一份班表），需要另外加上雲端資料庫與登入，請交給你的 AI 處理（見 `CLAUDE.md` 的「之後：多人共用」）。

## 要用在自己的診所

你不需要懂程式。準備好：

1. 一個 **Cloudflare 帳號**（放網站用，免費方案就夠）：https://dash.cloudflare.com/sign-up
2. 一個能幫你改程式的 **AI 工具**（例如 Claude Code）。

然後把下面這段話貼給你的 AI：

> 這是一個牙醫診所排班系統。請照裡面 `CLAUDE.md` 的說明，一題一題問我診所的設定（醫師、助理、看診時間、人數規則、假別），幫我改成我診所的樣子。改好後放到我的 Cloudflare，並且上鎖，只讓我們診所的人進得去。

AI 會讀 `CLAUDE.md`，接下來照它問的回答就好。

## 主要功能

- **每月排班流程**：人數（醫師與人數 → 管理者核准）→ 排休 → 排班（排班 → 行政檢查 → 管理者核准）→ 助理確認 → 正式公告。
- **醫師班表**：每週固定班、專科醫師來診日、休診日、單日調整；助理人數依醫師自動計算。
- **排休申請**：助理在開放期間申請整天排休或指定診次不排，看得到哪幾天比較熱門。
- **一鍵排班**：補齊每一診人數、照四週變形工時補到目標工時，盡量平均分配兩頭班、三診、連續晚診。
- **能力表與培訓**：誰能獨立跟哪位醫師、誰需要有人帶；培訓目標會排進一鍵排班。
- **值班主管、工作分配、排班統計、排班結果**。
- **手機版面**、白天／夜間模式、存成圖片、使用說明頁。

## 給工程師

需要 Node.js 20.9 以上。

```bash
npm install
npm run dev      # http://localhost:3000
npm run verify   # lint、typecheck、test、build
```

Next.js 靜態輸出（`output: "export"`），建置結果在 `out/`，可以放在任何靜態網站服務。
